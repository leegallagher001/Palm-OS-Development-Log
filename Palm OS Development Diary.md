**Palm OS Development Diary - Lee Gallagher**



*Entry 13/10/2026*



Over the past few days I have obtained a Palm m100, a Palm m105, a HotSync cradle and a USB-to-Serial adapter using a PL2302GT chipset. I tried unsuccessfully to set up a Palm OS desktop environment (Palm Desktop \& palmOne Quick Install) on a VM running Windows XP 32-bit, however I had more success using Windows 7 32-bit, where after several hours of trying, I was able to set up a HotSync between my laptop and my Palm m100. Both Palm devices run Palm OS Version 3.5.



As an entry point into Palm OS development, I chose to install the application "HotPaw Basic" also known as "yBasic" onto the Palm device. This is somewhat more of a way to experiment with Palm OS development rather than a serious way to create serious applications for the system, allowing the user to run programs written in the device's Memo Pad feature in a simplified version of old-school BASIC (comparable to Minimal BASIC). So far, I have used this to write a Hello World application as well as a Simple Calculator.



My plan is to spend a little more time with yBasic, then have a go with using NSBasic, which allows a user to design a Palm OS app using a graphical Visual Basic interface, and after that to go on to try development tools that use C. Over time I also plan to acquire more Palm devices - the Palm m130 as well as an m500-series device are two contenders for ones that I may try and pick up next.
